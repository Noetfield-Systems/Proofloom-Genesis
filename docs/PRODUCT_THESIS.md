# Product Thesis — Proofloom

**Build it. Prove it. Earn it.**

Proofloom is a new, independent human × AI builder economy. Its differentiator is not an AI code editor, a generic reward board or a freelance listing. It turns everyday human insight into real, reviewable software improvement tasks; people and authorized AI agents can then build, test, ship and verify outcomes. Participants earn skills, documented professional reputation, eligible conditional ecosystem rewards and eventually sponsored paid work.

The onboarding must be simpler than a developer IDE. A beginner should contribute meaningfully within a minute, without wallet setup, specialized tools or a paid subscription. The platform should become progressively more capable for a professional developer, maintainer or sponsor.

The durable loop is: **People contribute → AI agents build → Humans verify → Products improve → Contributors earn → Communities grow → Sponsors fund more work.**

Genesis beta proves the entry and review segment of this loop. It currently has no AI code execution, actual funded marketplace transaction or token issuance. Those must be independently implemented and measured before describing the entire loop as automated.

Independence is structural: separate identity, storage, branding, economics, roadmap and eventual treasury from Noetfield, ARQANT, BuildRelay, WorkforceOS, SignalForge, Cairn and Earnloop. They may later be authorized customers via explicit adapters, never automatic subsidiaries or shared funds.
