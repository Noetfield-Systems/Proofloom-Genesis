# Focused Competitive Benchmark Matrix

| Product | Verified mechanism or area to study | Proofloom adoption | Status |
|---|---|---|---|
| Zealy | Quests, XP, leaderboard, referral qualification | Missions, XP after approval, referral after actual qualified contribution | First iteration live |
| Superteam Earn | Sponsored bounties, project applications, talent pipeline | Public proof of work and sponsor inquiry, not yet funded offers | Partial |
| OnlyDust | Open-source contribution coordination, sponsor-funded contributor support | Evidence-based contribution reviews | First iteration live |
| GitHub | Issues, PR reviews, audit trail | External artifact URL intake | Native App planned |
| Lovable / Bolt / Replit / Cursor | Prompt-to-app development | Natural-language challenge submission | Full coding studio planned |
| Layer3 / DoraHacks / Gitcoin / Talent Protocol | Discovery, campaigns, public work and reputation | Roadmap inputs | Research stage |

Reference documentation: Zealy getting started (https://www.zealy.io/docs/contributor/getting-started), Zealy referral conditions (https://zealy.io/docs/tasks/invites), Superteam Earn types (https://docs.superteam.fun/the-superteam-handbook/community/faqs/superteam-earn-faq), OnlyDust support model (https://docs.onlydust.com/overview/how-do-we-flow), Superteam Earn open-source repo (https://github.com/SuperteamDAO/earn).

Differentiation: a completed mission should eventually produce a verifiable software change through a human/AI work pipeline, not engagement metrics alone. This release proves only the initial submit/review/proof segment, not the full differentiator.
