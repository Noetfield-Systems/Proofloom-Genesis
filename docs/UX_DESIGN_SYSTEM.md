# Visual and UX System

## Positioning
AI-native community builder economy; premium but low-friction. Not an internal agent console, an IDE clone, or a fake trading dashboard.

## Tokens
Background `#080b12`; cards `#121a27` / dark gradients; soft lines `#283548`; primary text `#eef4f6`; secondary text `#a4b0c0`; lime accent `#c7f77a`; mint `#95dfce`. Hero uses geometric workflow panels and restrained texture. Typography: Space Grotesk for prominent display; DM Sans for body (font fallback available).

## Navigation
Home · Missions · Vibe Studio · Community · Academy · Opportunities · Rewards; Join/Login/Profile prominent. Mobile scroll navigation; 1-column card stack under 680px.

## UX behavior
Visible live mission count and actual usage totals; clear task description, reward XP and requirement; one form to submit evidence; clear pending status; accepted public proof; funded opportunities honestly empty until confirmed.

## Known UX debt
Screenshot review not completed; no accessibility audit yet; form errors mostly via query string redirects; no language selection, inline AI studio, interactive live app preview, email notifications or responsive visual evidence screenshot. These remain acceptance tasks.
