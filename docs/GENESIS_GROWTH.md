# Genesis Growth — The First Wave

## Value proposition
**Build it. Prove it. Earn it.** Improve real software with prompts, tests, design or code. Earn verified XP today and build a public work portfolio; funded missions and on-chain participation come later when active.

## Distribution channels
Prioritize X, Farcaster, Reddit, Discord, Telegram, GitHub, Hacker News, AI coding groups, maintainers and independent builders. Lead with a clickable, beginner-friendly mission and the verifiable before/after loop, not a token-price prediction.

## Four activation loops
1. Mission share: challenge card → invite → useful first submission.
2. Proof share: accepted public proof URL → new builder signup → new meaningful contribution.
3. Project loop: visible accepted improvements → external project inquiry → sponsored mission.
4. Skills loop: beginner reproducible bug → reviewed proof → advanced task → paid professional opportunity when funded.

## Referral rule
An invitee's registration alone provides zero referral XP. A first accepted contribution awards 30 off-chain XP to the inviter, once. Avoid financial incentives for unverified accounts.

## Testable milestones, not achievements
First 100 real signups, 30 active first actions, 10 reviewed useful contributions, one independently verified release, one external sponsor and one positive-margin completed commercial transaction.

## Launch snippets
X/Farcaster: “You don’t need to be a developer to help build software. Find a bug, write a prompt, improve a screen, submit evidence. Real contributions become your track record. Join the Proofloom Genesis.”

GitHub/HN: “Proofloom is a lightweight experiment in human × AI software contribution. Public starter missions, persisted evidence, human-reviewed XP, and contribution proofs are live. We're looking for maintainers to pressure-test quality, onboarding and future GitHub integration.”

Avoid fabricated activity and artificial scarcity. The visible leaderboard starts empty until real work is accepted.
